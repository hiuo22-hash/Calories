# 하루 기록

하루 일과를 구글 캘린더 일간 보기처럼 시간표에 기록하고, 운동 소모 칼로리와 식사 섭취 칼로리를 함께 계산하는 모바일 웹앱(PWA)입니다.

## 기능
- **시간표 기록**: 빈 시간대를 탭하면 그 시간에 새 기록이 생깁니다. 블록을 **꾹 눌러 끌면 이동**하고, **아래 끝 손잡이를 끌면 길이가 조절**됩니다(5분 단위).
- **종류**: 📝 일상 · 🏃 운동 · 🍚 식사 · 📅 일정, ⭐ 중요 표시(상단에 따로 모아 보여줌)
- **운동**: 운동 종류(MET) × 체중 × 시간으로 소모 칼로리 자동 계산
- **식사**: 한식 위주 음식 목록에서 검색해 추가하고 인분 조절, 목록에 없으면 직접 입력
- **하루 요약**: 섭취 / 소모(기초대사량 × 일상 활동 + 운동) / 차이
- 칼로리는 언제든 직접 고쳐 쓸 수 있습니다.
- 기록은 휴대폰 브라우저에 저장되며, 설정에서 백업 파일 받기와 불러오기를 할 수 있습니다.
- 구글 캘린더로 보낼 기록을 표시해 둘 수 있습니다(실제 연동은 다음 단계).

## 휴대폰에서 쓰기 (GitHub Pages)
1. GitHub 저장소 → **Settings → Pages**
2. *Build and deployment*의 Source를 **Deploy from a branch**로 두고, 브랜치를 고른 뒤 폴더는 `/ (root)` → **Save**
3. 1~2분 뒤 표시되는 주소(`https://<아이디>.github.io/<저장소>/`)를 갤럭시 크롬에서 열기
4. 크롬 메뉴(⋮) → **홈 화면에 추가** → 앱 아이콘으로 실행

> 무료 계정은 저장소가 **Public**이어야 Pages를 쓸 수 있습니다.

## 계산식
- 기초대사량(Mifflin-St Jeor): 남 `10×체중 + 6.25×키 − 5×나이 + 5`, 여 `… − 161`
- 운동 소모: `MET × 체중(kg) × 시간(h)`
- 음식 칼로리는 1인분 기준 대략값입니다.

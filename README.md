# 하루 기록

하루 일과를 구글 캘린더 일간 보기처럼 시간표에 기록하고, 운동 소모 칼로리와 식사 섭취 칼로리, 목표를 함께 관리하는 개인 앱입니다.
claude.ai 아티팩트로 배포되며, 기록은 claude.ai 계정의 아티팩트 데이터베이스에 저장됩니다(소유자만 읽고 쓰기).

- 앱 주소: https://claude.ai/artifact/E7dvreKMUsZMzNuGFuc4UH

## 기능
- **시간표**: 빈 시간대를 탭하면 새 기록이 생깁니다. 블록을 **꾹 눌러 끌면 이동**하고, **아래 끝을 끌면 길이 조절**(5분 단위)이 됩니다.
- **종류**: 일상 · 운동 · 식사 · 일정, ★ 중요 표시(상단에 모아 보기)
- **운동**: 운동 종류(MET) × 체중 × 시간으로 소모 칼로리 자동 계산
- **식사**: 먹은 것을 글로 자유롭게 적으면
  - 앱에서 **지금 AI로 계산**을 누르거나,
  - 그냥 두면 **매일 새벽 1시(한국 시간)** 에 전날 식사를 Claude가 계산해 채워 넣습니다.
  - 자주 먹는 음식은 내장 목록에서 빠르게 추가할 수도 있습니다.
- **목표**: 하루 섭취 칼로리 목표(추천값: 소모량 − 500kcal), 주간 운동 시간·횟수 목표
- **통계**: 주간/월간 섭취·소모 막대 차트, 운동 시간 차트, 평균과 목표 달성 일수, 날짜별 표
- **루틴**: 하루 기록을 루틴으로 저장해 두고 다른 날에 한 번에 넣기

## 파일
| 파일 | 내용 |
|---|---|
| `index.html` | 페이지 (아티팩트 형식: doctype·head 없이 본문만) |
| `style.css` | 디자인 토큰과 스타일 (라이트/다크) |
| `app.js` | 화면, 드래그, 칼로리 계산, 통계, 루틴 |
| `store.js` | 저장소: claude.ai 데이터베이스, 없으면 브라우저 저장소 |
| `data.js` | 운동 MET 표, 음식 칼로리 목록 |

## 데이터 구조
```
days/<YYYY-MM-DD>   { date, entries: [기록...], updatedAt }
settings/profile    { sex, age, height, weight, activity, goals: { intake, exMinutes, exCount } }
routines/<id>       { name, items: [기록...], createdAt }
```
식사 기록의 `foodText`가 있고 `ai.forText`와 다르면 "계산 대기" 상태이며, 새벽 작업이 `ai`와 `kcal`을 채웁니다.

## 계산식
- 기초대사량(Mifflin-St Jeor): 남 `10×체중 + 6.25×키 − 5×나이 + 5`, 여 `… − 161`
- 하루 소모 = 기초대사량 × 일상 활동 계수 + 운동 소모
- 운동 소모: `MET × 체중(kg) × 시간(h)`
- 음식 칼로리는 추정치입니다.
